Quero implementar agora o bloqueio visual do frontend com base no plano retornado por:

GET /api/me/plan

IMPORTANTE:
nesta etapa NÃO quero criar novas regras de backend.
NÃO quero alterar webhook, Cakto, Firebase Auth, Firestore, entitlement ou segurança server-side.

A fonte de verdade já existe no backend.

Hoje /api/me/plan retorna:

{
  authenticated: true,
  plan: "essential" | "deluxe" | null,
  emailVerified: boolean
}

A regra desta etapa é:

- plan === "essential" → usuário tem acesso
- plan === "deluxe" → usuário tem acesso
- plan === null → usuário NÃO tem acesso

Por enquanto Essential e Deluxe devem ter EXATAMENTE o mesmo acesso no frontend.

Não diferenciar conteúdo entre os dois planos ainda.

==================================================
OBJETIVO
==================================================

Criar uma camada de controle de acesso visual no frontend.

Quero que usuários autenticados sem plano vejam o app, mas com o conteúdo bloqueado por um overlay premium.

Usuários com Essential ou Deluxe devem continuar usando o app normalmente, sem overlay.

==================================================
REGRA PRINCIPAL
==================================================

Criar uma lógica central equivalente a:

const hasPlan =
  plan === "essential" ||
  plan === "deluxe";

Se hasPlan === true:
→ app funciona normalmente

Se hasPlan === false:
→ mostrar overlay de bloqueio

Não duplicar essa regra em vários componentes.
Centralizar a lógica de forma reutilizável.

==================================================
CARREGAMENTO
==================================================

Muito importante:
